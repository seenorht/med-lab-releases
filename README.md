# منظومة المختبر الطبي المتقدمة - التوزيع والتحديث السحابي (Medical Lab System V3)

مستودع التوزيع والتحديثات السحابية الرسمية لمنظومة المختبر الطبي الشاملة (`Medical Lab System`).

---

## 🚀 أحدث إصدار: **V3.3.0** (تاريخ النشر: 15-11-2026)

### 🌟 أبرز مميزات التحديث V3.3.0:
1. **تخصيص تذييل تقرير CBC**: حذف العنوان ورقم الهاتف من تذييل تقرير CBC لإتاحة التخصيص الكامل للطباعة فوق أوراق المختبرات أو الفحوصات الجاهزة دون تكرار للبيانات.
2. **نظام الشيتات المخصصة المتعددة (Multi-Sheet Manager)**:
   - إمكانية إنشاء عدة شيتات في نفس الوقت للمريض الواحد (`+ إضافة شيت`).
   - خيارات متقدمة: تعديل عنوان التقرير، تصفير القيم، مسح التحاليل، نسخ الشيت، وحذف الشيت.
   - طباعة شيت فردي أو طباعة مجمعة لكافة الشيتات المفتوحة دفعة واحدة (كل شيت في صفحة A4 مستقلة).
3. **مكتبة التحاليل الشاملة (80+ تحليلاً بـ 7 تخصصات طبية)**:
   - بحث فوري لحظي بالاسم أو الرمز.
   - إضافة أي تحليل بضغطة زر وتلوين فوري للبطاقة.
   - منشئ التحاليل المخصصة وحفظها محلياً.
4. **8 باقات وقوالب طبية جاهزة**:
   - الفحص الشامل (General Checkup)، وظائف الكلى (KFT)، وظائف الكبد (LFT)، الغدة الدرقية (Thyroid)، السكري والمتابعة (Diabetes)، الفحوصات قبل العمليات (Pre-Op)، باقة الفيتامينات والمعادن، وباقة المفاصل والمناعة.
   - إمكانية حفظ أي شيت كقالب مخصص وإعادة استدعائه.
5. **قالب طباعة CBC (رأس وتذييل)**:
   - مخصص للطباعة المباشرة فوق أوراق أجهزة الـ CBC الجاهزة.
   - شريط المعايرة الملمترية لإزاحة الهيدر والفوتر والتحكم بإطار الورقة وحفظ الإعدادات تلقائياً.
6. **معادلة فريدوالد التفاعلية (Reactive Friedewald Formula)**:
   - حساب تلقائي لـ VLDL و LDL وتحديث فوري للملاحظة السريرية وتلوين القيم الحرجة حسب جنس المريض.
7. **الحفاظ التام على التراخيص العتادية**:
   - حماية ملف `license.lic` وربط بصمة الجهاز (HWID) دون الحاجة لإعادة التفعيل بعد التحديث.

## ⚡ طرق التحديث السحابي للحاسبات في المختبرات

### الطريقة الأولى: التحديث التلقائي بضغطة زر واحدة (من داخل البرنامج)
إذا كانت حاسبة المختبر تعمل على المنظومة:
1. افتح المنظومة وتوجه إلى شريط الإحصائيات العلوي أو قائمة الإعدادات.
2. اضغط على زر **`فحص التحديثات`** (أو انقر على إشعار التحديث السحابي الظاهر تلقائياً).
3. اضغط على **`تثبيت التحديث الآن`**.
4. ستقوم المنظومة بتنزيل التحديث وتثبيته وإعادة التشغيل تلقائياً خلال ثوانٍ معدودة.

---

### الطريقة الثانية: أمر التحديث السحابي المباشر عبر الإنترنت (PowerShell)
على أي حاسبة مختبر، افتح **PowerShell** والصق الأمر التالي واضغط **Enter**:

```powershell
irm https://raw.githubusercontent.com/seenorht/med-lab-releases/main/update.ps1 | iex
```
